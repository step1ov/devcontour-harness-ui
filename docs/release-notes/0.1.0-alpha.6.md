# devcontour-harness-ui 0.1.0-alpha.6 (не выпущен)

Пустое состояние больше не выглядит как идущая очередь. Peer прежний:
devcontour-harness `>=0.1.0-alpha.55 <0.2.0`; новые поля — из
devcontour-harness `0.1.0-alpha.62` (не выпущен), с прежними версиями панель
работает как раньше.

## Каталог, с которым ещё ничего не запускали

- harness сообщает `progress.queue.neverRun` — значок «Ещё не запускали»
  (нейтральный) и строка harness «Ещё ничего не запускали — ведущий начнёт с
  harness run.» вместо «Очередь идёт». Пауза по-прежнему важнее.
- Пустое состояние прежнего harness (предупреждение `STATE_NOT_FOUND`, работ
  нет) панель читает так же, строка — её словами.

## Почему нет среза прогона

- `scopeReason: no-snapshot` и пустое состояние — «harness ещё не читал задачи
  из трекера»; `unreadable` — «снимок задач трекера есть, но harness не смог
  его прочитать»; неизвестная причина называется как есть.
- «Эта версия harness не сообщает остальные задачи прогона» остаётся только
  для документа без поля, в котором что-то уже запускали.

  копии обновляются из опубликованного пакета); копии `0.1.0-alpha.60` — в
  `tests/contract/harness-0.1.0-alpha.60/`. Типы панели знают ключи
