# devcontour-harness-ui 0.1.0-alpha.8

Панель читает ревизию представления 6. Peer прежний: devcontour-harness
`>=0.1.0-alpha.55 <0.2.0`; новые разделы — из devcontour-harness
`0.1.0-alpha.66`, с прежними версиями всё работает, как раньше (каждое
поле ревизии 6 необязательно). Рекомендуемая пара — devcontour-harness
`0.1.0-alpha.66` и devcontour-harness-ui `0.1.0-alpha.8`.

## Ведущий

- «Журнал → Ведущий» (`#/lead`): идёт ли сессия ведущего, с какого
  времени и до какого срока действует отметка, строка harness, журнал
  новыми сверху — заметки ведущего и его команды harness (разбор, запуск,
  согласование…) со ссылками на работы; ссылка на ленту «Кто что делал» с
  фильтром по ведущему. Состояние выпуска и итоговый отчёт ведущего.
- На «Обзоре» — короткая панель: работает ли ведущий, с какого времени,
  последняя заметка, состояние выпуска.

## Прогноз

- Две цифры: «по утверждённому плану ~X %» и «с планируемыми задачами
  ~Y %» со строкой harness.
- Состояние выпуска («код в работе», «код принят, ведущий работает»,
  «выпуск готов»), доля ведущего и его шаги; под кругом — «код принят»,
  пока нет итогового отчёта. 100 % — только когда так прислал harness.
- «Цепочка зависимостей: не меньше N задач подряд» и время работы
  ведущего — строками harness.

## Задачи

- Путь задачи на карточке — строка сегментов: попытка — сегмент из шагов
  (код, проверки, ревью, интеграция), решения — ромбы, «принято» —
  квадрат. Серый — впереди, зелёный с пульсацией — идёт сейчас (без
  пульсации при «меньше движения»), красный — не прошло, янтарный — ждёт,
  синий — решение ведущего, фиолетовый — доработка, пустой кружок —
  пропущено. У каждого сегмента — текст для экранного диктора и подсказка.
- В «Весь процесс» — путь таблицей: №, попытка, шаг, состояние, время,
  причина, легенда словами; ранние шаги, отброшенные пределом, названы.
  Без пути (старый harness или документ, сокращённый по размеру) — так и
  сказано.
- Карточки «ещё не утверждена» для планируемых задач; такая задача не
  повторяется в «Ещё не переданы в harness». Работа с неутверждённым
  планом — своя фаза и значок.
- Доработка, отменённая прежней версией harness, показана принятой со
  значком «доработка отменена» и строкой harness.
- «Разбор ведущего» после повторных отказов (`DIAGNOSIS_REQUIRED`) и сброс
  попыток ведущим — ход ведущего («Делает ведущий»), одной строкой на
  остановку; в «Нужно от вас» их нет.

## Обзор

- «Что задействовано»: модели и вендоры, изоляция, инструменты,
  хранилище зависимостей, службы (docker: работает, остановлено, осталось
  после попыток), проверки — строками harness.
- «Посмотреть результат»: ссылки на превью принятого результата (только
  адрес `http://127.0.0.1:<порт>/` из harness, новая вкладка), что
  показано, когда запущено и когда остановится. Запуск и остановка —
  командами `harness preview-start` / `preview-stop`: панель по-прежнему
  только читает, кнопки придут вместе с первым путём записи.

## Настройки

- «Кто принимает решения»: итог одной фразой, предупреждение о необычном
  сочетании, каждая настройка — значение, откуда оно (политика, выведено,
  по умолчанию) и объяснение harness на языке панели.

## Для хостов (встраивание)

- Новые компоненты: `LeadJournal`, `LeadSummary`, `TrackLine`,
  `TrackTable`, `TrackLegend`, `ResourcesPanel`, `PreviewsPanel`,
  `DecisionsPanel`; модель пути — `drawnSteps`, `trackGroups`, `trackTone`,
  `trackAbsence`. `Overview` принимает `leadHref`.
- shadcn/ui-компоненты без новых зависимостей: `Table`, `Tooltip` (без
  портала), `StatusDot`. Новые токены `--hui-current`, `--hui-decision`,
  `--hui-rework`, `--hui-planned`.

## Договор

- Копии схем harness в `tests/contract/harness/` — от `0.1.0-alpha.66`, с
  настоящими ответами `harness view` для отсутствующего состояния и для
  репозитория до настройки; копии `0.1.0-alpha.65` — в
  `tests/contract/harness-0.1.0-alpha.65/`. Документы ревизии 5 проходят
  схемы alpha.66 и шлюз.
- Демо: пятая работа ждёт разбора ведущего, путь с разбором и доработкой,
  планируемая задача, журнал ведущего, «Что задействовано» и превью — на
  английском и в `fixtures/ru/`.
