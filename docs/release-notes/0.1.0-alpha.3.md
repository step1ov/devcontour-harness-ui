# devcontour-harness-ui 0.1.0-alpha.3

Исправление упаковки. В опубликованном `0.1.0-alpha.2` оказалась старая
сборка `dist` (до срезов S3 и ревизий 1–2): пакет собирался только вручную
перед `npm publish`, и без этого шага в архив попадал прежний `dist`. Такая
панель знает лишь ревизию 0 представления и с devcontour-harness
`0.1.0-alpha.56` и новее пишет «Данные новее панели — обновите
devcontour-harness-ui», а живых обновлений и экрана «Кто что делал» в ней нет.

Теперь `npm pack` и `npm publish` сами собирают пакет (`prepack` →
`npm run build`), поэтому архив всегда соответствует исходному коду версии.
Содержимое — то же, что задумано в `0.1.0-alpha.2` (живые обновления S3,
ревизии 1 и 2 представления). Peer прежний: devcontour-harness
`>=0.1.0-alpha.55 <0.2.0`; рекомендуемая пара — devcontour-harness
`0.1.0-alpha.58`.

## Обзор: кто действует дальше

Обзор остановленного прогона читался противоречиво: шапка писала «От вас:
принять 1 решение», рядом стоял «Нужен ваш ответ (0)», а «Ждут решения (2)»
не говорили, чьего. Теперь:

- Один раздел «Нужно от вас (N)» перечисляет и вопросы, и решения (сбросить
  попытки, увеличить бюджет…) — с тем, что сделать, почему и как. Число в
  шапке равно числу пунктов раздела; при нуле раздел пишет «Сейчас от вас
  ничего не нужно» без «(0)».
- «Остальные ожидания» разбиты по тому, кто действует: «Делает ведущий»
  (одинаковая причина нескольких работ — одна строка), «Делает <кто>» и
  «Ждут другой работы» с тем, кто дальше действует по той работе.
- Если сначала должен действовать ведущий (план нужно согласовать заново —
  `APPROVAL_STALE`), решение оператора говорит «Сначала ведущий: …. Потом —
  вы», а шапка — «принять 1 решение (после ведущего)».
- Группы отказов в строке попыток показаны словами («работа не доделана 2,
  время вышло 1, нужен ответ 1»), неизвестный ключ — как есть в `code`; так
  же в деталях работы.
- Работы в предложениях названы ключом заголовка («WEB-1»), коды и полные id
  — в раскрытии «подробности».
- Новое API модели: `nextSteps`, `actorsOn`, `attemptsLineParts`,
  `workName`, `knownLabel` (`devcontour-harness-ui/model`).
  `HeaderCounts.decisions` теперь — число решений оператора из `nextSteps`,
  а не эскалаций; новое необязательное поле `afterLead`.

## Обновление

`npm install --save-dev --save-exact devcontour-harness-ui@0.1.0-alpha.3` и
перезапуск панели. Данных панель не хранит, миграции нет. Версию
`0.1.0-alpha.2` лучше не ставить (`npm deprecate` — на усмотрение
публикующего).
